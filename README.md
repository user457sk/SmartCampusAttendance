# SmartCampusAttendance

A complete attendance management app for schools and campuses.

Features:
- Calendar-based date selection
- Date + time based attendance sessions
- Teacher / Admin / Student view toggle
- Student-wise attendance with Present / Late / Absent
- Summary calculations
- CSV export
- Print/PDF mode
- Student add form
- Persistent attendance data stored in JSON file

Running the app:

1. Install dependencies:
   npm install

2. Start the server:
   npm start

3. Open in browser:
   http://localhost:3000

The app stores attendance data in:
- data/attendance-data.json

This project uses Node.js + Express.
